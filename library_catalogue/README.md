\# Library Catalogue



A simple, interactive web application for managing and browsing a library catalogue.  

Built with \*\*semantic HTML\*\*, \*\*external CSS\*\*, and \*\*JavaScript\*\* for interactivity.



---



\## Features

\-  \*\*Search\*\*: Quickly find books by title, author, or keyword.

\-  \*\*Sort\*\*: Sort catalogue entries (e.g., by title, author, or year).

\-  \*\*Responsive design\*\*: Works across desktop and mobile devices.

\-  \*\*Clean UI\*\*: Styled with external CSS for maintainability.

\-  \*\*Interactive buttons\*\*: Event-driven JavaScript for smooth user experience.



---



\## Technologies Used

\- \*\*HTML5\*\* – semantic structure

\- \*\*CSS3\*\* – external stylesheet for design

\- \*\*JavaScript (ES6)\*\* – dynamic search and sort functionality
